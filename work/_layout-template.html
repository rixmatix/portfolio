Layout pattern library

Every layout available for case study pages, with real markup to copy. This page is not linked from anywhere and is marked noindex — it ships harmlessly, or delete it before launch. Each section has an HTML comment explaining usage.

layout/01

Full-width figure

The default. Spans the content container (1200px max).

layout/02

Full-bleed figure

Edge to edge: add spec-figure--bleed to the figure — from inside any container. Best for wide, atmospheric imagery.

layout/03

Centered figures

Add spec-figure--narrow or spec-figure--medium to the figure class.

layout/04

Half & half breakout

Copy left, image right

Use this when a single image needs explanation that deserves more than a caption. The columns vertically center against each other.

Add split--flip to the wrapper to mirror it.

Flipped variant

Same markup, one extra class. Alternate flipped and unflipped splits down a page for editorial rhythm.

layout/05

Sticky split

Pinned copy, scrolling media

The copy stays put while multiple images scroll by on the right. Good for showing several views of one idea without repeating yourself.

layout/06

3:4 portrait grid

Three portrait tiles, cropped to 3:4. Ideal for mobile screens.

layout/07

3/4 content with 1/4 aside

The aside column: a margin note, a stat, or a pull-fact that annotates the main content without interrupting it.

layout/08

Bento grid

Mixed-size tiles for a dense visual summary — images and stats together.

Numbered card trio

Joined cells sharing one frame — for problems, principles, or pillars.

    Flat token model

    Manual handoff

    Engineers copied brand colours and type specs by hand from Figma. Decisions were missed; rework was routine.

    No component / pattern boundary

    All UI routed through the DS before product teams could use it — a bottleneck that owned decisions belonging to product.
